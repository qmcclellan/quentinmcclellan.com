Featured project

StarkGrid

StarkGrid is a private MVP/demonstration platform for deterministic artifact ingestion, evidence review, and governed automation. Built in Java across seven active modules — Janus, Demeter, Argus, Themis, Hermes, Hephaestus, and Mnemosyne — running on Kafka and Docker Compose.

The system runs distributed across two lab nodes: Jarvis as the primary control-plane and Ultron as a GPU-capable remote worker. Athena (React) and athena-observer (FastAPI) provide read-only evidence review and DLQ visibility.

The case study demonstrates clear module ownership, deterministic processing boundaries, source-backed observability, and guardrailed claims — with explicit caveats for what has not been enabled.
